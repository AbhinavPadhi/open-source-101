A simple introduction

What is open source?

You have probably used open source software before without knowing it. Open source software is software where the source code is available for people to study, change and share, depending on its license.

What is open source?

Think of software like a recipe. With open source software, the source code is available to others. People can look at the code, learn from it and make changes when the license allows it.

The important part is not just that the software is free. Open source is also about being able to study, improve and share software.

Why use open source?

Open source can be useful for students because you can learn from real projects and see how software is made. It can also give you more choices when looking for software.

Learn

You can study real code and learn how software works.

Community

People can contribute code, report problems and improve documentation.

Transparency

The source code can be inspected by others.

Choice

You can find alternatives to proprietary software.

Open source and proprietary software

The main difference is who controls the source code and what users are allowed to do with it.

Open source

Source code Available under a license
Study the code Yes
Modify the code Depends on the license
Can it be free? Yes

Proprietary

Source code Controlled by the developer
Study the code Usually no
Modify the code Usually no
Can it be free? Yes or paid

What are open source licenses?

An open source license explains what people are allowed to do with the software. Different licenses have different rules.

MIT

A simple and permissive license that allows people to use, modify and distribute the software with certain conditions.

Apache 2.0

A permissive license with additional terms, including terms related to patents.

GPL

A license that allows people to use and modify software, with conditions that apply when modified versions are distributed.

Always check the actual license of a project before reusing its code.

Want to learn more?

You do not need to become a developer to understand open source. You can start by looking at a project on GitHub, reading its README and seeing how people contribute to it.

Open source is not just about getting software for free. It is also about how software can be shared, studied and improved.
