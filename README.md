# Open Source 101

Open Source 101 is a small static website that explains the basics of open source software in simple language.

It was created as part of a student research project about how students choose and use software.

## What the website covers

- What open source software means
- Why open source is more than just free software
- Examples of open source software
- Open source vs proprietary software
- Open source licenses
- A short interactive quiz

## Files

- `index.html` contains the website content
- `style.css` contains the design
- `script.js` contains the interactive examples and quiz
- `README.md` contains project information
- `LICENSE` contains the MIT License

## Run it locally

No installation is required.

Open `index.html` in a web browser.

## GitHub Pages

The project can be hosted using GitHub Pages.

After uploading the files to a GitHub repository:

1. Open the repository settings.
2. Go to Pages.
3. Select the main branch as the source.
4. Save the settings.
5. GitHub will provide the website URL.
